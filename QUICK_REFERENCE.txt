  • Lo-Fi   - Reduced high-end, boosted bass
  • Ambient - Smooth, gentle EQ curve
  • Rock    - Boosted bass and treble
  • Pop     - Slight high-mid boost

  • Electric - Punchy mids and highs

  • Can be manually saved/loaded

================================================================================
                            ARCHITECTURE OVERVIEW
================================================================================

MVVM Pattern:
  Model:      SettingsManager (persistence layer)
  ViewModel:  EqualizerViewModel (state management)
  View:       MainActivity (Jetpack Compose UI)
  Service:    EqualizerService (audio effects)

Data Flow:
  User Input → ViewModel → Service → AudioFx API → Audio Output
  ↑___________|_Service State_←_|_↓_Settings Persistence

Service Binding:
  LocalBinder Pattern
  One service instance per app
  Communicates via bound interface

Audio Effects:
  Primary:    DynamicsProcessing (20-band, modern)
  Fallback:   Equalizer API (5-band, legacy)
  Additional: BassBoost, Virtualizer, LoudnessEnhancer

================================================================================
                            TROUBLESHOOTING QUICK FIXES
================================================================================

Build fails:
  → Run: ./gradlew clean
  → Then: ./gradlew assembleDebug --no-daemon

APK won't install:
  → Check Android 9+ (API 28+)
  → Try: adb uninstall com.example.equalizersoftware

Audio not working:
  → Verify device supports AudioFx
  → Check service is running
  → Try other music app to verify device audio

Sliders not responsive:
  → Restart app
  → Check service binding
  → Clear app cache

Colors look wrong:
  → Check display brightness
  → Verify RGB color support
  → Try different device
